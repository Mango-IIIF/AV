Custom elements

Complete or composable

Use <mango-av-media> for the complete experience. Use <mango-av-player>, <mango-av-chapters>, <mango-av-transcript>, and <mango-av-annotations> independently by assigning them one shared controller.

import '@mango-iiif/av';

const controller = new AVPlayerController();
player.controller = controller;
chapters.controller = controller;
transcript.controller = controller;
annotations.controller = controller;
await controller.load(manifest);

Open the composable components demonstration.

Typed options

AVPlayerConfig

Configure controls, information panels, transcript behavior, resume storage, languages, start position, request handling, and annotation persistence.

player.config = {
  panels: { chapters: true, transcript: true },
  controls: { captions: true, playbackRate: true },
  resume: { enabled: true, ttlDays: 30 },
  resolveRequest: async (url, { canvas }) => sign(url, canvas)
};

Headless API

AVPlayerController

Use @mango-iiif/av/core when an application owns the UI. Playback methods include load, attachMedia, play, pause, seekTo, selectCanvas, next, previous, and selectSource.

Annotation methods are createAnnotation, updateAnnotation, and removeAnnotation.

Translations

Pass partial strings overrides in the controller configuration. The dictionary is shared by every connected component, while preferredLanguages selects IIIF language-map values and the Media Chrome language.

const controller = new AVPlayerController({
  preferredLanguages: ['cy', 'en', 'none'],
  strings: {
    chapters: 'Penodau',
    transcript: 'Trawsgrifiad',
    sourceNumber: 'Ffynhonnell {number}',
    resumePrompt: 'Parhau o {time}?'
  }
});

Integration

Events

The shared controller is an EventTarget and emits av-ready, av-error, av-canvaschange, av-sourcechange, av-play, av-pause, av-timeupdate, av-seek, av-ended, av-annotationschange, av-configchange, and av-statechange. Every connected component reacts to the same event stream.

Media Chrome themes

Styling

Theme through --mango-av-accent, --mango-av-background, --mango-av-surface, --mango-av-text, --mango-av-border, --mango-av-radius, and the standard Media Chrome variables. Replace regions with the header, before-player, player-overlay, controls, and after-player slots.

For full type signatures and normalized IIIF interfaces, see docs/API.md in the package repository.
